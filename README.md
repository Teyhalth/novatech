# NovaTech

**Find. Learn. Explore. Create with AI.**

NovaTech is an educational website designed to help users discover, learn about, and explore artificial intelligence. It provides accessible information about AI, introduces useful AI tools across different categories, and offers guides to help users understand how AI can be used responsibly and effectively.

## About the Project

NovaTech was created as a Web Development project for **BSIT**. The website focuses on making information about artificial intelligence easier to explore through a simple, organized, and user-friendly interface.

The project includes different sections that cover:

* Introduction and information about Artificial Intelligence
* AI tools and their different uses
* AI learning guides
* Responsible and informed use of AI
* Helpful resources for exploring AI

## Main Features

### Home

Introduces NovaTech and provides an overview of what users can explore on the website.

### AI Tools

Features selected AI tools organized into categories such as:

* Research
* Coding
* Writing
* Productivity
* Creative Work

### AI Guide

Provides simple guides and information to help users better understand and explore AI.

### What is AI?

Introduces basic AI concepts and encourages users to:

* **Inform** – Learn the basics of AI.
* **Discover** – Explore what AI can do.
* **Choose** – Find tools that fit different needs.
* **Responsible** – Verify information and use AI responsibly.

### Contact

Provides a way for users to reach out or send inquiries.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Design

NovaTech uses a modern dark navy and blue visual style designed to provide a clean and organized experience across different screen sizes.

The website is designed for:

* Desktop
* Tablet
* Mobile

## Project Status

**Currently in development**

The desktop version is being developed first, followed by responsive layouts for tablet and mobile devices.

## Purpose

NovaTech is developed for educational purposes as part of a **BSIT Web Development project**. Its goal is to provide an approachable space for learning about AI, discovering useful tools, and encouraging responsible use of artificial intelligence.
